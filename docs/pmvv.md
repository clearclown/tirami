# Tirami — Purpose / Mission / Vision / Values

このドキュメントは「Tirami は結局なんなのか」に一箇所で答えるためのものです。
README の書き方、新機能を入れるかどうかの判断、対外的な説明の言葉づかいは、
すべてここを基準にします。

---

## Purpose — なぜ存在するか

**知性へのアクセスを、支払い能力と所有ハードウェアから切り離す。**

## Mission — 何をするか

**ローカル LLM を動かす人どうしが、計算資源を融通し合えるようにする。**
単位は FLOP（1 TRM = 10⁹ FLOP）、決済は当事者2者の署名のみ。

## Vision — 目指す状態

**手元のハードウェアの大きさが、使えるモデルの大きさを決めない状態。**

## Values — 迷ったときの優先順位

1. **動くものだけを動くと言う。** 実装済み・設計済み・未着手を混ぜない。
   README の Status Honesty はこの価値の実装であって、免責事項ではない。
2. **投機ではなく計算。** TRM は計算量の単位。ICO なし、プレマインなし、
   運営取り分なし。総供給 21B は憲法的パラメータで、ガバナンスでは変えられない。
3. **誰がプロンプトを見るかを常に明示する。** 隠さない。よく見せない。
4. **ブロックチェーンを足さない。** 取引は当事者2者の署名で確定する。
   チェーンは最終的な証拠性が要る監査面だけの選択肢。
5. **1台でも成立する。** 経済機能は使わなければ意識せずに済むこと。

---

## 解こうとしている問題

### 前提: フロンティア API には4つの摩擦がある

1. **コスト** — 従量課金は使うほど増える。クラウド API が $5-15 / 1M tokens
   に対し、ローカル推論は電気代 $5-10 / 月。使用量が一定を超えれば逆転する。
2. **バージョンを固定できない** — 利用者はモデルのバージョンを固定も検証も
   できない。予告なく更新され、非推奨化され、同じプロンプトが同じ結果を返す
   保証がない。ローカルの GGUF はハッシュが同じなら明日も同じものです。
3. **アクセス** — 月額が払えない層、為替や地域の事情で払えない層が存在する。
4. **トラストバウンダリ** — プロンプトが第三者に渡る。規制業種や個人的な
   用途では、それだけで選択肢から外れる。

**この4つはローカル LLM で解けます。** そこまでは Ollama や LM Studio が
既に解いています。

### Tirami が解くのはその次

**ローカル LLM には壁があります。** 32B を Q4 で動かすのに約 20GB、70B で
約 40GB、100B+ の MoE で 50GB 以上。多くの人の手元にその機械はありません。
データセンタを建てるか、諦めて小さいモデルで我慢するかの二択になる。

**Tirami はこの壁を、機械を買うのではなく融通し合うことで越えます。**
持っている誰かに依頼し、依頼した分は借りになり、自分が引き受ければ返せる。

一文で言うと:

> **Ollama は「ローカルでモデルを動かす」を解いた。**
> **Tirami が解くのは「手元に載らないモデルを、データセンタなしで動かす」。**

## 3段階 — どこまでできていて、どこからできていないか

| 段階 | 内容 | 状態 | 制約 |
|---|---|---|---|
| **1** | 他ノードへ推論を依頼（転送） | **動作中** | 提供者側にモデルが載っている必要がある。プロンプトは提供者に平文で見える |
| **2** | LAN / Thunderbolt で複数台のメモリを束ねる | 開発中（[#162](https://github.com/clearclown/tirami/issues/162) / [#163](https://github.com/clearclown/tirami/issues/163)） | 低 RTT リンクが前提 |
| **3** | 広域でのメモリプール | 研究中 | 重み転送が RTT 律速（[#164](https://github.com/clearclown/tirami/issues/164) 実測） |

段階1と段階2・3を混ぜて語らないこと。**「休眠 PC を束ねて大きいモデルを動かす」
は段階2以降の話であり、今日動くのは段階1です。**

### 実測が段階1を支持している

[#164](https://github.com/clearclown/tirami/issues/164) で Mac mini M4 Pro ⟷
Mac Studio M4 Max の実機測定を行いました。

- **推論そのものは RTT にほとんど影響されない** — トークンあたり 3.83 往復。
  RTT が 9.2 倍（0.755ms → 6.97ms）になっても生成速度の低下は 1.36 倍に留まる。
  50ms の大陸間でも約 3.9 tok/s の見込み。
- **重み転送は RTT 律速で破綻する** — 17,434 MiB の転送が Thunderbolt で
  139.5 秒、有線 LAN で 867.5 秒。RTT 20ms の WAN に外挿すると約 40 分。
  リンク帯域の 6% しか使えていない。

つまり**広域で成立するのは「モデルを持っている人に頼む」であって、
「レイヤーを分けて配る」ではありません。** 段階3 が研究中なのはこのためです。

## 譲れない正直さ

### プライバシーを benefit として書かない

[`faq.md`](faq.md) は既にこう書いています。

> **At the serving node**: the node that runs inference **sees your prompt
> text**. This is an explicit trust boundary, not a solved privacy property.

段階1を使った瞬間、プロンプトは他人の機械に平文で渡ります。契約も保持ポリシーも
ある事業者より、その一点では弱い。**「プライバシーのためにローカル、だから
Tirami」と書くと、自分の FAQ と矛盾します。**

正しい主張はこうです。

> **Tirami が提供するのはプライバシーではなく、トラストバウンダリの選択権。**

今は「提供者に渡す」しか選択肢がありません。Tirami では、自分の機械で完結させる／
信頼する相手を指名する／匿名のピアに投げる、を用途ごとに選べます。
**選択肢が1つしかない状態からの脱却が価値**であって、暗号化された推論が
できるようになったわけではありません（それは zkML / TEE の領域で、まだ先です）。

### 「性能が乱高下する」とは書かない

利用者の体感としては広く報告されていますが、提供側は否定しており、外部から
実証する手段がありません。**検証可能な言い換えを使ってください。**

- ❌ 「同じ料金でも日によって性能が落ちる」
- ✅ 「利用者はモデルのバージョンを固定も検証もできない」

後者は事実で、しかも体感の正体を説明できています。

### 数字は再実測してから書く

README・翻訳・ドキュメントに載る数字は、コピーして持ち越さないこと。

```bash
cargo test --workspace                        # テスト数
./scripts/verify-impl.sh                      # 適合性
cd repos/tirami-contracts && forge test       # コントラクト
```

## メッセージング — 使う言葉 / 避ける言葉

### 避ける

| 表現 | 理由 |
|---|---|
| 「GPU Airbnb」 | ユーザーも語彙も立ち上がらない。誰が何をするのか伝わらない |
| 「分散 LLM 推論マーケットプレイス」 | 専門用語の連結。読み手の問題に接続しない |
| 「Proof of useful work ブロックチェーンプロトコル」 | 抽象的すぎる。しかも Tirami の中核はチェーンではない |
| 「計算は通貨である」を第一声にする | 経済理論の主張であって、読み手の利益ではない |
| Bitcoin との比較を冒頭に置く | 通貨の話から入ると、モデルを動かしたい人が離脱する |
| 「TRM は人間のための通貨ではない」 | 事実上「あなたは対象外です」と言っている |
| プライバシーを無条件の利点として書く | FAQ と矛盾する（上記） |
| 投資・値上がり・利回りを想起させる語 | TRM は金融商品ではない |

### 使う

| 表現 | 理由 |
|---|---|
| 「手元に載らないモデルを動かす」 | 読み手が持っている問題そのもの |
| 「1 TRM = 10⁹ FLOP」 | 単位の定義。曖昧さがない |
| 「依頼した分は借りになり、引き受ければ返せる」 | 経済の仕組みを比喩なしで言える |
| 「誰がプロンプトを見るかを選べる」 | 正確で、かつ実際に価値がある |
| 「まずは1台で試せます」 | 参入障壁がないことを最初に示す |
| 「未実装です」 | 段階2・3を語るときは必ず添える |
