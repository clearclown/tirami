# marketing/ — superseded drafts

**Everything in this directory predates both the rename and the current
positioning. Do not publish from it without rewriting.**

Two separate problems:

1. **Naming.** These files still say "Forge" and "Compute Units (CU)". The
   project is Tirami and the unit is TRM (1 TRM = 10⁹ FLOP).
2. **Positioning — the bigger one.** They lead with "GPU Airbnb",
   "distributed LLM inference marketplace", and the Bitcoin comparison.
   [`docs/killer-app.md`](../docs/killer-app.md) named the first two as
   phrasings to avoid, and [`docs/pmvv.md`](../docs/pmvv.md) now records why:
   they describe the mechanism to someone who has not yet been told what
   problem it solves.

A mechanical find-and-replace would fix (1) and leave (2), producing copy
that is correctly named and still says the wrong thing. So these are kept as
drafts rather than repaired in place.

**Before writing any announcement, read [`docs/pmvv.md`](../docs/pmvv.md).**
It carries the purpose, the three-stage honesty about what works today, and
the do/don't list for phrasing.
